# 三时市集地图

二级页面直接加载更新后的 morning.glb、noon.glb、night.glb，保留导出的世界尺寸和坐标。首页仍使用资产包内的微缩模型。

| 时段 | 可进入三级交互的摊位 | 四级商品 |
| --- | --- | --- |
| 早市 | 茶水摊、木铃摊、早餐摊 | 陶瓷杯；木铃、圆形瓷章；面包碟 |
| 午市 | 扇子摊、杂货摊、香囊摊 | 扇子；花纹袜子、小猫陶瓷罐；线香、骷髅蜡烛 |
| 夜市 | 古董摊、花灯摊、酿酒摊 | 时钟、拼图；华丽帽子；海星玻璃杯 |

商品模型路径以 assets/商品 为准，配置在 js/data/products.js；价格仍为演示价格。商品预览图在 assets/products。

配套 JSON 继续提供导航三角形、建筑阻挡、出生点及灯光。JSON 内的旧 stalls 列表不再用于建立交互入口；更新后的节点名、摊主位置和摊位朝向集中在 js/market/market-placements.js。Blender (x,y,z) 映射为网页 (x,z,-y)。

场景自带的骨骼角色由 js/market/characters.js 驱动，九位摊主按 NPCcharacter 目录对应；夜市酒摊和花灯摊使用对应独立角色文件替换原占位角色。其余角色保留为路人，仅在连续可行走的导航路径上往返。摊主保持原有面容，周期招呼和进入摊位时只轻微点头（约 4°），双手及躯干保持稳定；模型没有面部表情控制，不额外变形面部；减少动态效果偏好会停用这些循环动作。

js/market/shop-camera.js 使用场景真实几何检测镜头到摊主头部、上身、肩部以及柜台的视线，横屏和竖屏距离一起校验。

## 校验

使用 Node 22 或更新版本，在项目根目录运行：

```sh
node scripts/verify-market-assets.mjs
```

脚本检查三套场景加载、九个摊位、13 件商品与目录的一一对应关系、预览图、横竖屏镜头视线及骨骼动作，并将结果写到忽略提交的 .preview-check/verification.json。测试使用生产 GLTF 解析器，跳过贴图解码；不替代浏览器 WebGL 和交互验收。

主角使用 `assets/character.glb` 自带的 `walk.001` / `wait.001` 骨骼动画，身高手动设为 2.2 世界单位（摊主约 1.98–2.40），按待机姿势缩放并贴地。行走动画去除水平根位移，由导航统一控制移动，并按实际移动速度混合行走/待机，避免顶墙原地走或动画循环跳回。
