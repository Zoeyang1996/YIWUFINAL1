# 三时市集地图

二级页面直接加载由原 Blender 白模精修、组装后导出的地图，不再使用程序生成的直街。

| 时段 | 保留的原始空间 | 嵌入商铺 |
| --- | --- | --- |
| 早市 | 溪畔环路、桥、沿街建筑和树木 | 早餐、茶水、玩具、杂物 |
| 午市 | 百货院、手作院、连接廊及院落建筑 | 扇子、日用、杂货（两处） |
| 夜市 | 西侧山路、跨溪桥、东西平台与回程台阶 | 酿酒、古董、花灯、手作 |

原始 `独立白模.blend` 保留不变。同目录下的 `场景精修.blend` 是可编辑的完成版：已包含商铺、打包纹理、共享材质、灯光和总览相机。选中的白模店铺保留基座和台阶，以完整 GLB 商铺替换上部占位，避免屋顶和柜台重叠。

`morning/noon/night.glb` 包含完整地图和商铺，保留世界尺寸及坐标，不应再次归一化。配套 JSON 来自同一份 Blender 场景，记录导航三角形、建筑阻挡、出生点、商铺朝向和焦点。Blender `(x,y,z)` 映射为网页 `(x,z,-y)`。夜市补齐原桥头与道路之间的两处接续平台。

## 美术

统一青灰瓦、暖灰粉墙、旧榆木、赭色麻布、米灰石板和灰绿色植被；纹理已打包为图像而非仅 Blender 可用的程序节点。保留商铺原贴图，统一为较高粗糙度、低金属度。白天暖光、夜间冷环境光配暖灯。编辑版保留独立物件，网页导出时将环境按材质合并以减少绘制次数。

## 重新生成

在项目根目录运行（Blender 4.5）：

```sh
/Applications/Blender.app/Contents/MacOS/Blender -b --factory-startup --python scripts/build_markets.py
node --test tests/*.test.js
npm run dev
```

脚本默认从原白模重建并覆盖精修版。手动编辑精修版后，请另存副本再重建；原白模不会被覆盖。单独重建一个时段可在 Blender 命令末尾添加 `-- night`（或 `morning`、`noon`）。

`previews/markets/*-refined.png` 为 Blender 实际渲染的美术预览；网页灯光由 Three.js 设置，画面不应视为浏览器截图。
